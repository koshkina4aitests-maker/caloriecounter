# LifeTracker (калории + БЖУ + тренировки)

Небольшое локальное веб‑приложение для учёта:

- **Потребления**: еда/приёмы пищи, БЖУ и калории (калории считаются по БЖУ).
- **Расхода**: кардио (MET‑оценка или вручную) и силовые тренировки (подходы с весами/повторами + калории тренировки).
- **Прогрессии**: график динамики по упражнениям (e1RM по лучшему подходу в тренировке).
- **База**: предзаполненный набор базовых упражнений (можно добавлять свои).

Данные хранятся в **SQLite** файле `lifetracker.db` в корне проекта.

## Запуск

Требуется Python 3.12+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть в браузере `http://127.0.0.1:8000`.

## Как пользоваться

- **Продукты** (`/foods`): создайте шаблоны продуктов с БЖУ на 100г.
- **Еда** (`/log/food`): добавляйте записи по шаблону (в граммах) или вручную по БЖУ.
- **Кардио** (`/log/cardio`): добавляйте прогулки/бег/велосипед и т.п.; если ккал не указаны, они считаются по MET и вашему весу (в настройках).
- **Силовые** (`/workouts`): создайте тренировку и заносите подходы (упражнение, повторы, нагрузка кг). На странице тренировки можно сохранить **расход ккал** (вручную или по MET).
- **Прогресс** (`/progress`): выберите упражнение и смотрите график e1RM.

## Формулы

- **Калории по БЖУ**: белки 4 ккал/г, углеводы 4 ккал/г, жиры 9 ккал/г.
- **e1RM (Epley)**: \(1RM = w \cdot (1 + reps/30)\)
- **MET**: \(kcal = MET \cdot 3.5 \cdot weight(kg) / 200 \cdot minutes\)
